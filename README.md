# SERIES 0x2B — BLEND-TAPE

一个三幕滚动网站。主物件是一盒磁带：模型由本机 Blender **参数化重建**（真实尺寸、五层、**57 个命名零件**、全倒角、真 PBR）。第一幕它平放在镜面上陈列；第二幕**点它就能逐层拆开**，拆开后整机转为半透明、鼠标指到哪一层哪一层就实体化；第三幕把**站点自己的源码**当猎物，一只**点线蜘蛛**在上面爬行、吞掉 token、踢飞代码行。

界面文案只有**英文缩写与数字**。

## 分幕滚动：吸附 + 渐变转场

- **吸附式**：`html { scroll-snap-type: y mandatory }`，每幕 `scroll-snap-align: start` + `scroll-snap-stop: always` → **一次手势只前进/后退一幕**
- **渐变转场**：`updateFade()` 按「每幕中心 ↔ 视口中心」的距离驱动每幕的透明度与 26px 微位移；相邻两幕各约 45% 时完成交叉淡入淡出（用真实中心计算，所以某幕高于一屏也不会错位）
- 非当前幕 `pointer-events: none`，避免隔着半透明的幕点到按钮
- 叙事联动：进入第二幕自动"装载磁带"（PLAY + HALF），离开则停机，回到第一幕回到 REST

> **一个 CSS 陷阱（已修）**：`body` 上写 `overflow-x: hidden` 会让 `overflow-y` 的计算值变为 `auto`，**滚动容器从 `html` 变成 `body`** —— 于是加在 `html` 上的 `scroll-snap-type` 不生效，吸附与深链互相打架（`?act=2` 会漂到第三幕或退回第一幕）。
> 改用 **`overflow-x: clip`**（现代写法，不创建滚动容器）后，吸附、`?act=N` 深链、`?state=N` 全部正常。

### 二↔三 转场卡顿的四个真实成因（都已修）

| # | 成因 | 修法 |
|---|---|---|
| 1 | `updateFade()` 每次滚动事件都读 `offsetTop/offsetHeight` 再写 style → **每次 3 次强制回流**，而吸附动画期间滚动事件极密 | 几何**缓存**（只在加载/视口变化时量一次），`updateFade` 只写不读 |
| 2 | 第三幕那层约 **3 万个 DOM 元素**，切进来时整层 opacity 变化 → 整层重新栅格化 | 未启用时 `content-visibility: hidden`（跳过整棵子树的渲染/布局）；淡入**延迟 140ms**，让首次栅格化发生在幕布还黑着的时候 |
| 3 | `body[data-act="3"]` 切换 `--bg` → **整页重绘** | 去掉 `--bg` 切换（body 始终保持米白），变黑完全交给幕布 |
| 4 | `stats()` 每帧遍历全部 3 万 token | 改为每 8 帧算一次 |

### 米白 → 黑的过渡：一层幕布（`#veil`）

**不用**改 `body` 背景色 —— 那会整页重绘。改为在画布之上叠一层全屏黑色遮罩，**只动它的 `opacity`**：

- `veil.style.opacity = t`，`t` = 「第二幕中心 → 第三幕中心」的滚动进度（第二幕居中为 0，第三幕居中为 1）
- 改 opacity 是**纯合成操作**（GPU，不触发重绘）→ 既顺滑，又正好**把第三幕首次栅格化的卡顿盖在"背景变黑"的过程里**
- `#veil` 的 `z-index: 1`：盖住页面背景与两个 canvas，但在幕内容（z-index 5）与爬虫层（z-index 2）**之下**，所以第三幕的代码仍然清晰可见

### 三态与渲染
- `REST` / `HALF`（标签层 +4.6mm）/ `SPLIT`（label +30、frame +16、reels +2、body −13、back −26 mm）
- **旋转一致性**：第二幕整机不再持续自转（只有第一幕陈列时转）；卷轴与轮毂**各绕自身轴**自转 —— 之前用整层绕 Y 转，等于让两个卷轴**公转**

## 音频（本轮未改动）

| 轨 | 来源 | 行为 |
|---|---|---|
| **MAIN** | MiniMax Music 3 生成的 Lo-Fi → **123.6s** | 仅磁带触发时播放 |
| **BED** | 同模型冷清环境音，6 段变奏 + 尾→首交叉淡化 → **144.0s 无缝循环** | 页面启动即播（与 `arm()` 同步）；**磁带触发时先渐变静音（1.6s 淡到 0），静音完成后主轨才渐入（0.9s）**；停止时反之（主轨先 0.7s 淡出，再让次轨原位渐入 1.5s）。次轨的源**从不停止** → 位置始终保留，回来时原位续接 |
| **SFX** | Web Audio 参数化合成（无素材） | 逐次重掷频率/滤波/包络；**不使用脉冲类音效** |

> 音频时序全部用 **AudioContext 时钟排程**（`linearRampToValueAtTime` + `source.start(t0)`），不用 `setTimeout` —— 所以"次轨静音 → 主轨渐入"的先后关系是采样级准确的，不会因主线程卡顿而错位。

量化实测：MAIN 123.60s（mean −19.2 / max −1.2 dB）｜BED 143.99s（首 −50.0 / 末 −52.1 dB → 循环无缝）。

## 第三幕蜘蛛的规则（v8）

| 规则 | 实现 |
|---|---|
| 纯 2D | 腿只在屏幕平面内摆动：膝关节 = 把髋→足方向旋转**固定夹角 52°**、取 58% 处。无任何伪 3D 抬腿 |
| 身体 | **只有一个圆点**（品红），没有第二个体节 |
| 腿 | **八条等长**：足端落在半径 46px 的等距角度上（每侧 64°/25°/−21°/−60°），髋部 6.5px |
| 步态 | **交替四足组** `[0,2,5,7]` ↔ `[1,3,4,6]`：每走 15px 触发半周期，组内按 50ms 错开 |
| **踩着代码走** | 身体被 `clampToBand()` 夹在该列代码文字带内，**右界按蜘蛛附近几行的最长行计算**（不是整列）→ 不会走到短行右侧的空白里；**腿在 33~63px 内找不到 token 时【不抬脚】**，保持踩住，绝不落到空白处 |
| 落脚 | 抬脚时在该腿允许半径带（0.72R~1.36R）内找最近的 token 踩上去；两腿不重复踩同一个 |
| 踩住 | 落地 → 该 token 加 `pressed`（绿框）；踩住期间脚随 token 一起滚动 |
| 踢掉 | 抬脚离开时 50% 概率（0.35s 限流）把该 token **物理抛落**：初速朝远离蜘蛛方向（130~320px）+ 随机旋转（±310°），多关键帧走抛物线并带一次小弹跳 |
| **跟随鼠标（不过紧）** | 目标**每 0.45s 重评一次**（否则会一路走向过期目标）；评分 = 自体距离×0.42 + 鼠标距离×0.58，且**鼠标 130px 内的 token 视为等价好**（不贴着光标抖） |
| **吐丝飞越** | 鼠标在哪半屏就想去哪半屏：侧别不同时吐丝滑翔（二次贝塞尔，1.15s，八足收起并画出丝线），2.6s 冷却；**落地时身体正落在 token 上**，清掉旧侧落点、八足归位后由步态重新踩到附近代码上；右下 `FLY n / IN AIR` 可验证 |
| 吃 | **只吃变量**（`v` 类普通标识符），不吃标签/关键字/字符串/数字/注释 |

> **关键 bug（已修）**：token 是 `<i>`（inline 元素），而 **`transform` 对非替换 inline 元素无效** —— 所以"踢掉"的位移与旋转被整个忽略，看起来只是淡出消失。修法是给 `.cl i` 加 `display: inline-block`。

1. **Blender `transform_apply` 的默认参数陷阱**：只写 `rotation=True` 时 `location` 仍默认为 True → 位置先被烘进网格，再绕**世界原点**旋转，几何被甩飞（前缘倒角跑到 Z 16~20mm，轮毂的 10 颗齿也绕错中心）。必须显式 `location=False`。
2. **尺寸越界**：由上面那条导致的 Z=26.18mm；修正后为 12.22mm（倒角只允许出界 0.2mm）。
3. **第三幕代码残留在前两幕背景上**（用户报的严重 bug）：`main.ts` 只在 `act===3` 时调用 `crawler.draw()` → 离开第三幕后再没有一帧去隐藏它。改为每帧都调用，由爬虫内部按 `body[data-act]` 决定显隐。
4. **零件公转**：整层 `reels` 绕 Y 转会带着两个卷轴绕中心公转；改为各自绕自身轴自转。
5. **内嵌源码会过期**：`source.ts` 只生成过一次 → 页面上显示旧版源码。已把 `embed-sources.mjs` 并入 `npm run build`。

## 性能（审计后逐项修）

审计基线（数出来的，不是估计）：第三幕内嵌本站 7 个源文件 = **2,604 行 / 96,687 字符**，DOM 实际 **5,208 个行 div + 10,609 个 `<i>` token ≈ 26,233 节点**。

| # | 问题 | 为什么卡 | 修法 |
|---|---|---|---|
| 1 | `backdrop-filter` 用在 8~9 块区域（底栏 / 4~5 面板 / 3 按钮） | **每帧每块重算背景模糊**，背后正是持续动画的 WebGL 画布 | 全删，改更高不透明度的纯色底 |
| 2 | `will-change: transform` 加在 `.crawl-col`（每列 ≈13,500px） | 建 **783×13500 合成层 ≈42MB/列** | 去掉，改 `contain: layout paint` |
| 3 | `will-change` 常驻三幕 + 幕布（6 个整屏层） | **40MB+ 显存永不回收** | 只在转场期加 `.animating`，约 0.2s 后摘除 |
| 4 | 第三幕整屏占据时仍在渲染 WebGL | 每帧一个 2880×1620 MSAA 缓冲 + 63 draw call 白跑 | 补间走完后 `return` + 磁带 `visible=false` |
| 5 | 实时阴影 2048² + 每帧重算 + 114 网格 | 每帧一次完整阴影 pass | 1024 + `autoUpdate=false` + 每 4 帧 |
| 6 | 镜像副本 57 网格用 `scale=0.001` 隐藏 | 隐藏后**仍被渲染** | `visible=false` |
| 7 | `setPixelRatio(min(dpr,2))` | dpr=2 时像素量是 1.5 的 1.8 倍 | 上限 1.5 |
| 8 | 每帧 7 次 `querySelector` + 2 次 `fmt()` + `#a2-live` 重建 | 每帧 HTML 解析 + flex 重新布局 | 节点引用提模块级、`fmt` 一次、骨架只建一次 |
| 9 | 每帧 35 次 `setAttribute` + ~50 次 `toFixed` + 8 次 `class` 写 | `points` 每次重解析；`class` 写触发样式重算 | 去 `toFixed`、`class` 仅变化时写、trail 循环拼串 |
| 10 | `els()` 每次 `querySelector` + `Array.from`（≈35/帧） | ≈1,470 次属性读 + 140 次数组分配/帧 | 行内 `code` 按行缓存 + `nextSibling` 遍历 |
| 11 | `content-visibility` 一次性解除 26k 节点跳过 | 单任务内完成整层布局+绘制 → 顿挫 | 两列错开 90ms 分块揭示 |
| 12 | `.kicked` 的 `will-change` 挂满 18s（动画仅 1.15s） | 成百上千 token 白当独立合成层 | 类 1.2s 后摘除，数据仍留 18s |
| 13 | `.pressed` 的 `box-shadow`、`#dot` 脉冲、`--meter` 动 `width` | 都是**非合成属性** → 每帧重绘/布局 | 改 `outline` / `transform+opacity` / `scaleX` |
| 14 | `levels()/wave()/spectrum()` 每帧 new 类型数组 | ≈58KB/s 常量垃圾 | 复用预分配数组 |
| 15 | `crawler.stats()` 扫描全部 token | O(n) | 增量计数 → O(1) |
| 16 | `pointermove` 在看不见的目标上做全部分派 | 指针事件 120~240Hz | 按幕分派 + 只读一次坐标 + `passive` |

> 审计里有条建议**没采纳**：把 `#veil` 提到爬虫层之上（`z-index:3`）。第三幕幕布不透明度是 1，那样会把代码层整片盖黑 —— 幕布必须待在爬虫层**之下**（现状），顿挫改用"分块揭示"摊平。

## 与最初冻结边界的偏离（累计）

| 边界项 | 实际做法 | 原因 |
|---|---|---|
| 3 件 3D = 磁带三个状态 | **1 件 57 零件统一模型承担全部三态** | TRELLIS 输出是 7164 个碎片的碎壳网格，无法拆解；参数化重建后一个模型即可 |
| 40+ 张 2D | **全部程序化生成**（PIL 贴图 + Canvas 绘制） | 生成模型拼英文必乱；文案是"英文缩写+数字"，代码绘制更锐利 |
| 第三幕"完全复现参考视频2" | **不复现**（用户明确指示）：改为仿生点线蜘蛛吃信息 / 踢代码行，取消特写放大 | 用户要求 |
| 第三幕内容 | 站点自身源码（7 文件 / 1804 行，构建时内嵌，零运行时请求） | 用户要求"滚动字幕改为 html 代码行" |
